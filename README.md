# The Find List

A responsive affiliate lifestyle website for curated home, lifestyle, seasonal, and trending finds.

## Editing content

Open `content.js` to add or change categories, products, collections, articles, and Amazon affiliate links.

Open `index.html` to change page copy, navigation links, disclosures, contact details, or social links.

Run `node generate-blog.js` after changing product names or product links to rebuild the 30 product guides and blog index.

Open `styles.css` to adjust colors and styling.

## Preview

Open `index.html` in a browser or serve this folder with any static web server.
